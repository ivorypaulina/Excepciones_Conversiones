# Manejo de Excepciones y Conversión de Datos en Java

Tarea realizada para la materia de Programación Orientada a Objetos en Java.

## Temas trabajados
- Manejo de excepciones
- Uso de try, catch y finally
- Excepciones personalizadas
- Conversión implícita y explícita
- Conversión entre String y tipos primitivos

## Actividades realizadas

### Actividad 1
Programa que solicita un número entero al usuario y divide 100 para ese número utilizando manejo de excepciones.

### Actividad 2
Sistema de registro de estudiantes utilizando una excepción personalizada para validar edades incorrectas.

### Actividad 3
Ejercicios de conversión de datos:
- Conversión implícita
- Casting explícito
- Conversión String ↔ tipos primitivos
- Casting de objetos

### Actividad 4
Sistema de conversión de monedas con manejo de excepciones y validación de monedas soportadas.

## Tecnologías utilizadas
- Java
- IntelliJ IDEA
